# Inverted World A+ Viral Product Goal

## Current Grade

Elon-interest grade: C+.

Why: the site now has a real visual identity, embedded video, AI/news scaffolding, and a Recursiv agent path, but it still does not yet feel unavoidable. The missing pieces are live cultural pulse, complete archive ingestion, actual member utility, daily publishing, and a receipts-first status loop that makes users compete to find primary sources.

## A+ Goal

Make `invertedworld.on.recursiv.io` the conspiracy/paranormal intelligence desk people cite before they post.

It must:

- Let anyone immediately ask about anything without choosing filters.
- Embed the complete Tales From the Inverted World YouTube archive when `YOUTUBE_API_KEY` or an accepted YouTube Data API alias is configured.
- Maintain a browsable database of official documents, court records, declassified archives, science datasets, and news indexes.
- Publish a daily AI-assisted news issue with sources, image prompts, X hooks, and source packs.
- Use Grok/X API for live narrative pulse and X-native distribution.
- Use Claude for long-form document-grounded reasoning.
- Use Recursiv for org/project infrastructure, account state, agents, saved research, and publishing workflows.

## Viral Loop

1. X trend or source drop enters the pulse scanner.
2. Agent builds a claim ledger: record, rumor, weird read, skeptical read, unknowns.
3. System generates a short viral brief, source pack, quote card, thumbnail, and thread hook.
4. Members improve the ledger by adding documents or contradictions.
5. The best receipts and researchers are credited in the next daily issue.

## Product Gates

- Chat: no required filters, no dead-end signup, useful answer on first prompt.
- Archive: `/archive` embeds available uploads and uses YouTube Data API for full historical pagination.
- News: `/news` shows current sourced briefs and `/api/autopost/daily` returns daily publish packets.
- Documents: source records should strengthen story pages and AI answers; the standalone `/documents` and `/api/documents` shelves are removed until the experience is worth the click.
- Sources: article pages and agent answers must separate documented facts, allegations, speculation, and open questions.
- Mobile: first screen must show brand, live animation, chat, and account entry without layout collisions.

## Next Integrations

- `YOUTUBE_API_KEY`: full uploads playlist pagination. `YOUTUBE_DATA_API_KEY`, `GOOGLE_YOUTUBE_API_KEY`, and `GOOGLE_API_KEY` are also accepted aliases.
- `X_API_BEARER_TOKEN`: trends, posts, metrics, and distribution.
- `XAI_API_KEY`: Grok-powered X-native synthesis and memetic framing.
- `ANTHROPIC_API_KEY`: deep document reasoning.
- `RECURSIV_SERVER_API_KEY`: production agent chat and saved member workflows.
- `IMAGE_GENERATION_API_KEY`: generated thumbnails and share cards.

## A+ Standard

The product earns A+ only when a user can land on mobile, ask a wild question, get a nuanced receipts-first answer, open the exact relevant videos and documents, read a daily brief worth sharing on X, and feel like joining gives them powers they cannot get from a generic chatbot.
